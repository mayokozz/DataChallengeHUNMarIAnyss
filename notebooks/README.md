# Notebooks

Ejecutar en este orden (requieren acceso a los datos del reto; no se incluyen):

1. `eda_person.ipynb` — personas
2. `eda_visits_occurrence.ipynb` — visitas (base de la demanda)
3. `eda_visits_detail.ipynb` — detalle de visitas
4. `eda_condition_occurrence.ipynb`, `eda_procedure_occurrence.ipynb`, `eda_measurement.ipynb` — diagnósticos, procedimientos y mediciones
5. `modeling/hourly_demand_forecasting.ipynb` — pronóstico de demanda por hora (Random Forest). Genera el CSV de pronóstico, que debe guardarse fuera del repositorio.

Las salidas guardadas muestran solo agregados, sin filas de pacientes.
